mornie プライバシーポリシー

mornie!（以下「運営者」といいます）は、運営者が提供するアプリ「mornie」（以下「本アプリ」といいます）における利用者の情報の取り扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」といいます）を定めます。

1. 対象アプリ

本ポリシーは、本アプリ「mornie」に適用されます。

2. 取り扱う情報

（1）本アプリに記録される情報

本アプリでは、利用者が入力した日々の気持ちやできごとなどの記録内容を取り扱います。

記録内容の保存場所や保存方法などの詳細は、今後の仕様確定に応じて本ポリシーに記載・更新する場合があります。

（2）お問い合わせの際にいただく情報

利用者が運営者へメールでお問い合わせをされた場合、運営者は以下の情報を受け取ります。

  • 送信元のメールアドレス
  • お問い合わせの内容
  • その他、利用者がお問い合わせの際に任意でご提供くださった情報（お名前、ご利用端末、アプリのバージョンなど）

3. 利用目的

運営者は、取り扱う情報を以下の目的の範囲内で利用します。

  • 本アプリの機能を提供するため
  • お問い合わせへの回答や、必要なご連絡を行うため
  • 不具合の調査・修正、および本アプリの改善のため

4. 第三者への提供

運営者は、法令に基づく場合を除き、利用者の同意なく、お問い合わせでいただいた情報を第三者に提供することはありません。

5. 情報の管理

運営者は、お問い合わせでいただいた情報について、漏えい・紛失・不正な利用などが起こらないよう、適切な管理に努めます。

6. お問い合わせ先

本ポリシーおよび本アプリにおける情報の取り扱いに関するお問い合わせは、以下までご連絡ください。

運営者：mornie!
メールアドレス：mornie.official@gmail.com

7. 本ポリシーの改定

運営者は、本アプリの仕様変更や法令の改正などに応じて、本ポリシーを改定することがあります。改定後の内容は、本ページに掲載した時点から効力を生じるものとします。重要な変更がある場合は、本ページ上でわかりやすくお知らせします。
